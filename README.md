# NOBLE NARA
Projeto em desenvolvimento que busca desenvolver, migrar e unificar tecnologias da cadeira de rodas autônoma NARA no ROS2 em uma versão mais atualizada e eficiente
* O projeto inclui dois subprojetos, "nara-sim" para a simulação e "nara-main" para a cadeira física
* Abra "Simulação.md" para ler o tutorial de como utilizar a simulação
* O desenvolvimento da cadeira física ainda está nas etapas mais iniciais, para mais detalhes leia o arquivo "Cadeira.md"
* Paralelamente está sendo criado uma IHM, um site atualizado propriamente para a interação humano-máquina propriamente para este projeto, tanto para a cadeira física quanto para a simulação que pode ser encontrada no repositório "noblenara-ihm"
